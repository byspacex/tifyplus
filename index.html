Tify Plus Mimari & Sistem Haritası

Tify Plus, istemci tarafında (Client-Side) çalışan, sıfır sunucu veri tutulumuyla tam gizlilik sağlayan ve resmi Spotify Web API ile doğrudan haberleşen bir uygulamadır.

1. OAuth 2.0 PKCE

Client Secret gerektirmeyen, SHA-256 Code Challenge ile tarayıcıda doğrudan üretilen en güvenli yetkilendirme akışı.

2. Akıllı Önbellek

Kütüphane ve şarkı verileri yerel localStorage'a önbelleklenir; gereksiz API çağrıları ve 429 Rate Limit önlenir.

3. Mükerrer Matrisi

Tüm listelerinizdeki şarkılar global bir hash tablosunda taranarak çapraz listede varlık haritası (Cross-Presence) çıkarılır.

4. Güvenlik Geri Al

Yapılan her aktarma veya birleştirmeden önce otomatik Safety Snapshot alınır; istenilen ana tek tıkla dönülür.

5. Akıllı Füzyon

Müzik türü ve ortak şarkı oranını analiz eden eşleştirme motoru listeleri mükerrersiz birleştirir.

6. Web Mini Player

Spotify hesabı bağlandıktan sonra Web Playback SDK ile doğrudan orijinal tam parça oynatma.
